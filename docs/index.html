AL_Cheatmenu

An in-game cheat window for Amanatsu Location. Press F7 to edit every heroine's stats and levels, energy, H and massage counts, H gauges, the time of day and the global flags. Changes apply to the live save immediately.

Loader
BepInEx 6 IL2CPP, be.788 or newer
Size
one 28 KB DLL
  1. Install BepInEx 6 IL2CPP (tested with 6.0.0-be.788) and run the game once.
  2. Merge the release zip's BepInEx folder into the game folder. This adds BepInEx\plugins\AL_Cheatmenu\AL_Cheatmenu.dll.
  3. Load a save and press F7.

To uninstall, delete BepInEx\plugins\AL_Cheatmenu. Everything the window changes stays in memory until you save the game.

Features

Heroines

One panel per heroine in the loaded save. Favorability, Inclusiveness, Proactivity and Curiosity each have level −/+, Max, add points and reset. Levels and point totals come from the game's own PropertyData tables, so they match what the game expects. Late points, energy, H count, massage count and the H gauge stages sit on the same panel. "Max everything" and "Refill energy" act on all heroines at once.

Time and flags

Set the time of day (morning, afternoon, evening, night, night event) or advance one zone with the game's own cycle logic. Mark the tutorial done or reset it. Mark all help screens seen and add the global unlock flags.

Behaviour

The mouse is unlocked while the window is open, values refresh every 1.5 s so game-driven changes show up, and a status line confirms each action.

How it works

A MonoBehaviour is injected into IL2CPP with ClassInjector.RegisterTypeInIl2Cpp on a persistent object; Update polls the toggle key through Unity's legacy Input, which this game still uses.

The window is uGUI + TextMeshPro built from code: Canvas, panel, header, tab row, a ScrollRect body and a status line. IMGUI is not an option here: the IL2CPP build stripped most of it and Il2CppInterop's unstripping fails (Method unstripping failed), so GUILayout.Button and friends throw. The TMP font asset is borrowed from the game (TMP_Settings.defaultFontAsset, else the first font asset in memory). Button callbacks go through DelegateSupport.ConvertDelegate<UnityAction>.

Data lives in Manager.Game.Instance.SaveData: NPCDataList entries carry GameParameter (the four stats as ParameterInfo {Point, LV, IsMaxLv}, LatePoint, Cost), GameCount (H, Massage) and HParameter.GaugeStage[]. SaveData.Cycle.TimeZone holds the time of day, and Manager.Game.Instance.GlobalData holds the help-seen and unlock flags. Level tables come from AL.PropertyData.Instance.GetPointParameter(i).

Troubleshooting

F7 does nothing

Check BepInEx\LogOutput.log for AL Cheat Menu … loaded. If another plugin or the game binds F7, change "Toggle key" in the config.

The window opens but the text is invisible

No TextMeshPro font asset was found to borrow. The About tab prints which font it uses; send the log.

"No save data loaded yet"

The window reads the live save; load or start a game first.

A change didn't stick

Save the game. Time-of-day changes apply when the game next evaluates the cycle (a map or scene change).
